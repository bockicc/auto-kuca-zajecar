# AGENTS.md

## Project

Auto kuća Zaječar — React + TypeScript + TanStack Router/Start + Tailwind CSS.

## Rules

- Use TypeScript with strict types; avoid `any`.
- Use the `@/*` path alias for imports from `src`.
- Keep feature code inside `src/features/<feature>`.
- Shared, reusable UI lives in `src/components/ui`.
- User-facing text goes through `src/lib/i18n` (Serbian first).
- Add tests next to the feature in `__tests__` or in `src/test`.
- Do not edit `src/routeTree.gen.ts`; it is generated by TanStack Router.

## UI/UX

- Load the `ui-ux-pro-max` skill (`.opencode/skills/ui-ux-pro-max/SKILL.md`) before designing, building, or reviewing any interface, component, layout, or design system.
- Follow its design rules, component patterns, and stack guidance; prefer its local data searches over generic assumptions.

## Commands

- `bun run dev` — start the dev server
- `bun run build` — production build
- `bun run test` — run unit tests
- `bun run lint` — lint the codebase
- `bun run typecheck` — TypeScript check
- `bun run format` — format with Prettier
